# Argus 市場価値試算レポート v1

## 1. 概要

本レポートは、登録した Web ページの更新有無を手動で確認する Windows デスクトップアプリ **Argus** の、2026年8月6日時点における市場価値を現在の実装、仕様書、テスト、配布確認結果に基づいて概算したものです。

これは実際の売却価格や会計・税務上の資産価値を保証するものではありません。主に、同等品を再構築するコスト、製品として譲渡する場合の価値、再利用できる技術資産の価値を可視化することを目的とします。

| 項目 | 内容 |
| --- | --- |
| 対象 | Argus |
| レポート版 | v1 |
| 試算日 | 2026-08-06 |
| 評価基準 | 2026-08-06 時点の `HEAD`、仕様書、実装、テスト、マニュアル、Release 検証記録 |
| 製品形態 | Windows 10 / 11向け .NET 8 WinForms デスクトップアプリ |
| ライセンス | MIT License |
| 現在の段階 | 初期 MVP 完了、Windows x64 self-contained single-file 発行確認済み |

重複を除いた技術・開発資産としての総合推定価値は、次のレンジが妥当です。

## **総合推定価値: 約 2,300,000～5,200,000円**

ただし、売上、継続利用者数、配布実績、商標、サポート契約などが確認できないため、第三者への現状有姿での実売・譲渡価格はこれより低くなる可能性が高く、別途 **約300,000～1,200,000円** を目安とします。

## 3. 評価方法

以下の3軸で試算します。

| 評価軸 | 内容 |
| --- | --- |
| A. 開発コスト換算価値 | 同等の完成度を持つアプリを第三者が再構築する場合の代替コスト |
| B. プロダクト市場価値 | 現状の製品・ソース一式を譲渡または販売する場合の価値 |
| C. 技術資産価値 | Core、テスト、設計文書、安全な保存・比較処理などの再利用価値 |

2026年の単価参考値として、Findyの調査ではIT/Webフリーランスエンジニアの平均時間単価は5,319円、エン株式会社の調査では2026年1月の案件平均月額単価は76.6万円とされています。本試算では、設計、実装、テスト、配布までを一人で担当できる人材を想定し、工程に応じて **5,500～9,000円/時** を使用します。

## 5. プロダクト市場価値

| 観点 | 評価 | コメント |
| --- | --- | --- |
| 課題の明確さ | 高い | 複数ページを毎回開く手間を減らす用途が分かりやすい |
| 完成度 | 中～高 | 初期MVPの機能、テスト、発行物の起動確認まで完了 |
| 独自性 | 中 | 手動一括チェックと誤検知抑制は有用だが、類似のWeb監視サービスや拡張機能は存在 |
| 導入容易性 | 中 | single-file化済みだが、インストーラーや署名済み配布物は未整備 |
| 対応範囲 | 低～中 | Windows専用、静的HTMLテキスト比較のみ。SPA、認証、CSSセレクタには未対応 |
| 収益性 | 未検証 | 売上、価格、利用者数、継続率の実績がない |
| 運用負担 | 低い | サーバー不要、ローカルJSON保存で固定費が小さい |
| 横展開性 | 中 | CSSセレクタ比較や小説サイト別モードへの拡張余地がある |

現状は「完成した個人向けユーティリティ」または「小規模製品のMVP」に位置します。収益実績を根拠にした倍率評価はできないため、ソースコード、仕様、テスト、マニュアルを含む現状有姿の譲渡価値として試算します。

**プロダクト市場価値: 約300,000～1,200,000円**

上限寄りの評価には、実行ファイルの配布権、名称・ロゴ等の権利、リポジトリ履歴、仕様・テスト・マニュアル一式、短期間の引き継ぎ支援を含むことを想定します。MIT Licenseで公開済みのコードだけを譲渡する場合、買い手の独占性がないため下限を下回る可能性があります。

| 区分 | 試算価値 |

| 開発コスト換算 | 2,500,000～5,000,000円 |
| プロダクト市場価値 | 300,000～1,200,000円 |

3区分は単純加算しません。プロダクトと技術資産の大部分は開発コストに含まれており、同じ価値を二重計上するためです。

総合推定価値は、第三者が同等品を作り直すコストを中心に、完成度、再利用性、文書・テスト資産を加点し、狭い対応範囲、収益実績の欠如、公開MITコードの非独占性を減点した値です。

## 8. 強みと減価要因

### 強み

1. **MVPが完了している**
   - 中核機能だけでなく、UI、永続化、エラー保護、配布確認まで揃っています。
2. **仕様と実装の追跡性が高い**
   - FR/NFR、設計、T-001～T-018、テストの対応が明文化されています。
3. **小規模アプリとして品質資産が厚い**
   - 66件の自動テストとRelease検証記録があり、引き継ぎ時の不確実性を抑えています。
4. **運用コストが小さい**
   - サーバーや外部DBが不要で、利用者のPCだけで完結します。
5. **Coreを再利用しやすい**
   - UIから業務ロジックが分離され、将来のUI変更や監視モード追加に適しています。

### 減価要因

1. **収益・利用実績がない**
   - 顧客基盤や将来キャッシュフローを評価できません。
2. **対応範囲が限定的**
   - Windows、HTTP/HTTPS、静的HTMLテキスト比較に限定されています。
3. **一般消費者向け配布が未完成**
   - インストーラー、コード署名、自動更新、問い合わせ窓口がありません。
4. **競合との差別化がまだ弱い**
   - Web監視サービス、ブラウザ拡張、RSS等の代替手段があります。
5. **公開ライセンスによる非独占性**
   - MIT公開部分だけでは、買い手が競合利用を排除できません。

## 10. 結論

Argusは大規模システムではありませんが、単なるWeb取得サンプルでもありません。**要件定義から設計、TDD実装、WinForms UI、安全なJSON保存、エラー時のデータ保護、Release発行、利用マニュアルまで完結した、小規模かつ完成度の高いWindowsユーティリティ**です。

したがって、個人開発の技術・開発資産として値付けする場合、現時点の妥当なレンジは次のとおりです。

# **約230万～520万円相当の技術・開発資産**

一方、実際に第三者へ売却する価格は、売上や利用者実績がなく、MIT公開コードに独占性がないことから、現状では **約30万～120万円** を現実的な目安とします。今後、署名付き配布、利用実績、差別化機能、収益実績が加われば、プロダクト市場価値を再試算できます。

## 11. 前提と留意事項

- 本試算は概算であり、正式な企業価値評価、知的財産評価、税務評価ではありません。
- 売上、利用者数、ダウンロード数、保守実績は提示されていないものとして評価しています。
- コード行数は空行・コメント・デザイナー生成コードを含む単純集計で、価値の主根拠ではありません。
- 既存のNuGetパッケージ、.NET、WinForms等の第三者資産そのものは評価額に含めません。
- 将来機能は未実装のため、現在価値には含めていません。
- 実売価格は、譲渡範囲、独占権、引き継ぎ支援、商標・ドメイン、公開状況によって大きく変動します。
