# Argus

Argus は、登録した Web ページが前回の確認時から更新されたかを、手動でまとめて確認するための Windows デスクトップアプリです。

ブログ、お知らせ、配布ページ、更新履歴などを一つずつブラウザで開く手間を減らします。自動監視や通知は行わず、ユーザーが必要なときにチェックを実行するシンプルなアプリです。

詳しい操作方法は [Argus ユーザーマニュアル](Manual/index.html) を参照してください。

## 主な機能

- HTTP/HTTPS の Web ページを監視対象として追加、編集、削除
- 登録した全ページまたは選択したページを手動でチェック
- HTMLテキスト、HTML全体、CSSセレクタで抽出した範囲を前回の内容と比較
- 「初回取得」「更新なし」「更新あり」「エラー」の状態を一覧表示
- 登録したページを Windows の既定ブラウザで表示
- 監視対象と前回の正常なチェック結果をローカルの JSON ファイルへ保存
- 通信エラーが発生しても、前回の正常な比較データを保持

## 動作環境

- Windows 10 / Windows 11
- .NET 8 SDK

現時点ではインストーラーやビルド済み実行ファイルを配布していません。ソースコードからビルドして実行してください。

## ビルドと起動

リポジトリのルートで、次のコマンドを実行します。

```powershell
dotnet restore
dotnet build Argus.sln
dotnet run --project Argus.WinForms
```

## 基本的な使い方

1. アプリを起動し、「追加」から名前と HTTP/HTTPS URL を登録します。
2. 「全件チェック」または「選択をチェック」を実行します。
3. 一覧に表示される更新状態を確認します。
4. 必要に応じて対象を選択し、「ブラウザで開く」からページを表示します。

Ctrl キーを押しながら行を選択すると、複数の監視対象を選択できます。

## データ保存

監視対象と前回のチェック結果は、次のローカルファイルに保存されます。

```text
%APPDATA%\Argus\targets.json
```

登録した URL などのデータを外部データベースへ送信する機能はありません。更新確認時には、登録された Web ページへ HTTP/HTTPS でアクセスします。

## 初期版の制約

- チェックはボタン操作時だけ実行され、自動監視、常駐処理、スケジュール実行、通知は行いません
- ログイン、Cookie、CAPTCHA が必要なページには対応していません
- JavaScript 実行後に内容が生成される SPA の解析には対応していません
- HTML全体比較はコメントや空白を含むすべての変化を検知するため、必要に応じてHTMLテキスト比較またはCSSセレクタ比較を使用してください
